    URL & Domain Evidence

    LEXICAL
    What do these parameters mean?

    URL length measures the scheme-independent address. Path length counts the path portion. Dots and subdomains describe URL structure, not safety on their own. Suspicious keywords counts selected phrases found in the URL. DNS A indicates an IPv4 lookup response; MX concerns incoming mail handling and may legitimately be absent. DNS presence does not verify website ownership or trustworthiness. Brand-reference status compares domain identity against a limited configured list. An official-reference match is not an independent security certification, and an unknown brand is not necessarily dangerous.
